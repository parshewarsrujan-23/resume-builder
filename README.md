# Resume Builder

A simple and professional **web-based Resume Builder** that helps users create a structured resume by entering their personal, educational, technical, and professional information.

The application provides an easy-to-use interface for creating a professional resume and downloading the generated resume as a PDF.

## 🌐 Live Demo

**Live Website:**
https://parshewarsrujan-23.github.io/resume-builder/

## 📌 Project Overview

Resume Builder is a frontend web application developed to simplify the process of creating a professional resume.

Instead of designing a resume manually, users can enter their information through a user-friendly form. The application organizes the entered information into a professional resume format that can be reviewed and downloaded.

## ✨ Features

* 📝 Enter personal and contact information
* 🎓 Add educational qualifications
* 💼 Add work experience
* 🚀 Add projects
* 🛠️ Add technical and professional skills
* 📜 Add certifications
* 🏆 Add achievements
* 👤 Optional profile photo
* 📄 Generate a professional resume
* ⬇️ Download the resume as a PDF
* 💻 Responsive and user-friendly interface
* 🎨 Clean and professional resume layout

## 🛠️ Technologies Used

* **HTML5** – Used to create the structure of the application
* **CSS3** – Used for styling, layout, and responsive design
* **JavaScript** – Used for form handling, dynamic content generation, and resume functionality

## ⚙️ How to Use

1. Open the **Resume Builder** website.
2. Enter your personal information.
3. Add your education details.
4. Add skills, projects, experience, certifications, and achievements.
5. Upload a profile photo if required.
6. Review the generated resume.
7. Download the completed resume as a PDF.

## 🚀 Running Locally

To run the project on your computer:

### 1. Clone the repository

```bash
git clone https://github.com/parshewarsrujan-23/resume-builder.git
```

### 2. Open the project folder

```bash
cd resume-builder
```

### 3. Run the application

Open `index.html` in a web browser.

No backend server or database is required for the current version.
